바닐라 HTML/CSS/JS로 "수업용 결과물 갤러리"를 만들어줘.
빌드 도구, 프레임워크, npm 패키지 없이 브라우저에서 index.html을
더블클릭하면 바로 동작해야 해.

[폴더 구조]
gallery/
├─ index.html
├─ assets/style.css
├─ assets/app.js
├─ data/examples.js
└─ examples/ux-menu/01-top-nav.html ~ 06-bottom-tab.html

[데이터]
data/examples.js 는 window.GALLERY_DATA = {...} 형태로 작성.
fetch/JSON 사용 금지 (file:// 에서 동작해야 함).
스키마:
{
  galleries: [{
    id, title,
    groups: [{ id, label }],
    items: [{
      id, title, group, summary, file,
      when, pros: [], cons: [], bestWidth: "desktop"|"mobile"
    }]
  }]
}

[화면 구조 - 3층]
1층 상단 가로 탭: 갤러리 전환 (홈페이지 / UX·UI 메뉴 / 디자인).
   지금은 "UX·UI 메뉴"만 데이터가 있고 나머지는 비활성 표시.
2층 좌측 사이드바: 분류 필터. groups 기준 + "전체".
   이동이 아니라 필터임이 드러나게 선택 상태를 체크 표시로 처리.
   화면 폭 900px 이하에서는 상단 가로 칩 줄로 전환.
3층 카드 그리드: 3열, 폭이 좁아지면 2열→1열.
   카드 = 라이브 미리보기 + 제목 + 한 줄 요약.

[카드 라이브 미리보기]
각 카드 썸네일 영역에 <iframe src="예제파일"> 를 넣고
transform: scale(0.35) + transform-origin: top left 로 축소.
iframe 은 pointer-events: none, loading="lazy", 스크롤 숨김.
카드 전체가 클릭 영역.

[상세 오버레이 모달]
카드 클릭 시 모달로 열림.
- 상단: 예제 제목 + 닫기 버튼
- 폭 전환 세그먼티드 컨트롤: 데스크톱(100%) / 태블릿(768px) / 모바일(390px)
  → iframe 컨테이너 폭만 바뀌고 예제는 실제로 반응해야 함
- 예제는 브라우저 창 모양 프레임(상단 바 + 신호등 점 3개) 안에 표시
- 하단 접이식 설명 패널: when / pros / cons
- "새 창에서 열기" 링크
- ESC 키로 닫기, 배경 클릭으로 닫기, 열릴 때 body 스크롤 잠금

[디자인 원칙 - 중요]
갤러리 자체 UI는 무채색으로 최대한 얌전하게.
예제 화면이 주인공이고 갤러리 크롬이 시선을 뺏으면 안 됨.
예제와 갤러리를 구분하기 위해 예제는 반드시 창 프레임 안에 넣을 것.

[예제 6개 실제 작성]
각각 독립 실행 가능한 완결된 HTML 한 장으로 작성.
가짜 콘텐츠(대시보드 형태)를 넣어 실제 서비스처럼 보이게 할 것.
01 상단 가로 탭 - 항목 4개
02 좌측 사이드바 - 항목 8개
03 그룹형 사이드바 - 항목 12개, 섹션 3개, 접기/펼치기 동작
04 세그먼티드 컨트롤 - 1차 상단 탭 + 2차 알약형 3개
05 햄버거 드로어 - 모바일 폭 기준, 실제로 열리고 닫히게
06 하단 탭바 - 모바일 폭 기준, 탭 4개, 항상 하단 고정

주석을 한글로 충분히 달아줘. 수업 자료로 쓸 거라 학생이 코드를 읽고
이해할 수 있어야 해.
