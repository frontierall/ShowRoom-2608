# ShowRoom-2608 — 수업용 결과물 갤러리

UX·UI 메뉴 패턴 예제를 모아 보여주는 **정적 갤러리**입니다.
빌드 도구·프레임워크·npm 패키지를 쓰지 않습니다.

**공개 주소 → https://frontierall.github.io/ShowRoom-2608/**

## 실행 방법

브라우저에서 위 주소를 열거나, 내려받아 `gallery/index.html` 을 **더블클릭**하면 됩니다.
서버가 필요 없습니다.

> 데이터를 `fetch()` 나 JSON 파일이 아니라 `window.GALLERY_DATA` 전역 변수로 넣어 둔 이유가 이것입니다.
> `file://` 로 열면 보안 정책(CORS) 때문에 `fetch()` 가 막힙니다.

## 폴더 구조

```
gallery/
├─ index.html                  3층 구조(상단 탭 / 분류 필터 / 카드 그리드) + 상세 모달
├─ assets/
│  ├─ style.css                갤러리 UI 스타일 + 반응형
│  └─ app.js                   상태(state) → 렌더 구조. 프레임워크 없음
├─ data/
│  └─ examples.js              window.GALLERY_DATA — 예제 목록 데이터
└─ examples/ux-menu/
   ├─ 01-top-nav.html          상단 가로 탭 (항목 4개)
   ├─ 02-side-nav.html         좌측 사이드바 (항목 8개)
   ├─ 03-group-nav.html        그룹형 사이드바 (12개 / 3섹션, 접기·펼치기)
   ├─ 04-segmented.html        세그먼티드 컨트롤 (1차 탭 + 2차 알약형)
   ├─ 05-drawer.html           햄버거 드로어 (모바일)
   └─ 06-bottom-tab.html       하단 탭바 (모바일, 탭 4개)
```

예제 6개는 각각 **독립 실행 가능한 완결된 HTML 한 장**입니다.
갤러리를 거치지 않고 파일 하나만 열어도 그대로 동작합니다.

## 화면 구조

| 층 | 역할 | 좁은 화면에서 |
|---|---|---|
| 1층 상단 가로 탭 | 갤러리 전환 (홈페이지 / UX·UI 메뉴 / 디자인) | 좌우 스크롤 |
| 2층 좌측 사이드바 | 분류 필터 (선택 시 `✓` 표시) | 900px 이하에서 상단 가로 칩 줄로 전환 |
| 3층 카드 그리드 | 라이브 미리보기 + 제목 + 한 줄 요약 | 3열 → 1100px에서 2열 → 640px에서 1열 |

카드 썸네일은 스크린샷이 아니라 **실제 `<iframe>` 을 `scale(0.35)` 로 축소한 것**입니다.

## 상세 모달

카드를 클릭하면 열립니다.

- 폭 전환 세그먼티드 컨트롤: 데스크톱(100%) / 태블릿(768px) / 모바일(390px)
  — 미리보기 프레임의 **폭만** 바뀌므로 예제 안의 미디어쿼리가 실제로 반응합니다
- 예제는 브라우저 창 모양 프레임(상단 바 + 신호등 점 3개) 안에 표시
- 하단 접이식 설명 패널: 언제 쓰나 / 장점 / 단점
- 새 창에서 열기, `ESC`·배경 클릭으로 닫기, 열려 있는 동안 뒤 화면 스크롤 잠금

## 예제 추가하기

`gallery/data/examples.js` 의 `items` 배열에 항목을 하나 더 넣고,
`file` 에 적은 경로에 HTML 파일을 만들면 끝입니다. 다른 파일은 건드릴 필요가 없습니다.

```js
{
  id: 'my-example',
  title: '07. 새 예제',
  group: 'horizontal',              // groups 의 id 중 하나
  summary: '한 줄 요약',
  file: 'examples/ux-menu/07-my-example.html',
  when: '언제 쓰는지',
  pros: ['장점1', '장점2'],
  cons: ['단점1', '단점2'],
  bestWidth: 'desktop'              // 'desktop' | 'mobile'
}
```

## 설계 원칙

갤러리 자체 UI는 무채색으로 최대한 얌전하게 만들었습니다.
**주인공은 예제 화면**이고, 갤러리 크롬이 시선을 뺏으면 안 되기 때문입니다.
예제와 갤러리를 눈으로 구분하기 위해 예제는 반드시 창 프레임 안에 넣습니다.

코드 주석은 수업 자료용이라 "무엇을 했는지"보다 **"왜 그렇게 했는지"** 를 적어 두었습니다.
